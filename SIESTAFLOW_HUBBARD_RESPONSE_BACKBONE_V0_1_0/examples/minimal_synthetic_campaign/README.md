# Campaña sintética mínima

Este ejemplo usa dos sitios y cuatro observables espín-resueltos. Su propósito es demostrar que:

- la cardinalidad no está hardcodeada a seis sitios;
- una transformación `2 x 4` produce matrices de sitio `2 x 2`;
- la metodología y el candidato están bloqueados;
- `recommended_single_U_ev` permanece nulo;
- no se requiere SIESTA para validar los contratos.

Los hashes de geometría y runtime son valores sintéticos con formato válido; no representan
archivos científicos reales.
