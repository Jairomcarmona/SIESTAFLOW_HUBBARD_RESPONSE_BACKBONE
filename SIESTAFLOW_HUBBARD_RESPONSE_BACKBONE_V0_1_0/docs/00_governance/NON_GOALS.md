# No objetivos

La versión inicial NO DEBE:

- implementar DFPT;
- declararse equivalente a `hp.x`;
- inferir automáticamente oxidaciones, valencias o manifolds;
- elegir sitios Hubbard sólo por elemento químico;
- relajar geometrías durante una matriz de respuesta;
- calcular automáticamente un `J` independiente;
- soportar SOC o magnetismo no colineal;
- usar pseudoinversa para ocultar una matriz no cuadrada;
- seleccionar un único `U` sólo porque aparece un plateau;
- hardcodear materiales, geometrías, números de sitios, pseudopotenciales o particiones;
- aceptar salidas por presencia de cadenas de texto aisladas;
- modificar datos originales durante análisis o aprobación.


## Convenciones normativas

Las palabras **DEBE**, **NO DEBE**, **DEBERÍA**, **NO DEBERÍA** y **PUEDE** son normativas.  
Una regla marcada como DEBE es obligatoria para conformidad. Una regla marcada como DEBERÍA
puede omitirse sólo con una justificación registrada y auditable.
