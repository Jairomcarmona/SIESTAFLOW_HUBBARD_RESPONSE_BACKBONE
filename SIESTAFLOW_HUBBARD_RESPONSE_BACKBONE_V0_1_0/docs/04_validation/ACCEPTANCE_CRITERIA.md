# Criterios de aceptación del backbone

Esta columna vertebral se acepta si:

- no contiene lógica específica de material en contratos generales;
- las cardinalidades son dinámicas;
- los esquemas validan el ejemplo;
- el DAG es materializable;
- las matrices rectangulares no se invierten;
- la selección de matriz está bloqueada;
- las decisiones humanas están separadas;
- la identidad incluye geometría, PSML, binario y banner;
- la taxonomía de fallos es explícita;
- las pruebas adversariales requeridas están enumeradas;
- el verificador del backbone pasa.

No implica aceptación del futuro backend SIESTA.


## Convenciones normativas

Las palabras **DEBE**, **NO DEBE**, **DEBERÍA**, **NO DEBERÍA** y **PUEDE** son normativas.  
Una regla marcada como DEBE es obligatoria para conformidad. Una regla marcada como DEBERÍA
puede omitirse sólo con una justificación registrada y auditable.
