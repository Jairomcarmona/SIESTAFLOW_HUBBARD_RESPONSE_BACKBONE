# Taxonomía de fallos

## Categorías

- `INPUT_INVALID`
- `RUNTIME_IDENTITY_MISMATCH`
- `SCHEDULER_FAILURE`
- `MPI_FAILURE`
- `SCF_NOT_CONVERGED`
- `OUTPUT_INCOMPLETE`
- `PARSER_AMBIGUOUS`
- `BARE_UNPROVEN`
- `MAGNETIC_STATE_CHANGED`
- `NONLINEAR_RESPONSE`
- `INSUFFICIENT_SIGNAL`
- `DATASET_INCOMPLETE`
- `ANTISYMMETRY_EXCESS`
- `RANK_DEFICIENT`
- `ILL_CONDITIONED`
- `INVERSION_RESIDUAL_EXCESS`
- `SENSITIVITY_EXCESS`
- `MANIFEST_MISMATCH`
- `POLICY_VIOLATION`
- `HUMAN_REJECTED`

Cada fallo DEBE incluir clase, severidad, tarea, evidencia, mensaje, recuperabilidad y acción
sugerida.


## Convenciones normativas

Las palabras **DEBE**, **NO DEBE**, **DEBERÍA**, **NO DEBERÍA** y **PUEDE** son normativas.  
Una regla marcada como DEBE es obligatoria para conformidad. Una regla marcada como DEBERÍA
puede omitirse sólo con una justificación registrada y auditable.
