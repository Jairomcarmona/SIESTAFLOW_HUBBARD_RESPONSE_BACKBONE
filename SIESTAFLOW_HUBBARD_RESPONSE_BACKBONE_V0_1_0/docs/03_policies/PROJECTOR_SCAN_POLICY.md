# Política de barrido de proyectores

## Fases

1. rejilla gruesa;
2. centinelas por clase explícita de sitios;
3. descarte temprano;
4. refinamiento local;
5. congelamiento de candidatos;
6. matriz completa sólo para candidatos congelados.

## Métricas

- estabilidad SCF;
- señal;
- linealidad;
- continuidad magnética;
- respuestas cruzadas centinela;
- condición preliminar;
- estabilidad local.

El barrido no debe considerar únicamente el valor diagonal de `U`.


## Convenciones normativas

Las palabras **DEBE**, **NO DEBE**, **DEBERÍA**, **NO DEBERÍA** y **PUEDE** son normativas.  
Una regla marcada como DEBE es obligatoria para conformidad. Una regla marcada como DEBERÍA
puede omitirse sólo con una justificación registrada y auditable.
