# Gates numéricos

Cada gate se configura mediante nombre, métrica, operador, umbral, unidad, severidad y política
ante datos faltantes.

## Gates mínimos

- completitud;
- convergencia;
- señal;
- linealidad;
- curvatura;
- asimetría alpha;
- estabilidad magnética;
- antisimetría matricial;
- rango;
- condición;
- residuos de inversión;
- sensibilidad;
- replicación;
- integridad de manifiesto.

## Antisimetría

\[
a(A)=\frac{||A-A^T||_F}{\max(||A||_F,\epsilon)}.
\]

La simetrización sólo es admisible después de PASS.


## Convenciones normativas

Las palabras **DEBE**, **NO DEBE**, **DEBERÍA**, **NO DEBERÍA** y **PUEDE** son normativas.  
Una regla marcada como DEBE es obligatoria para conformidad. Una regla marcada como DEBERÍA
puede omitirse sólo con una justificación registrada y auditable.
