# Fases de implementación recomendadas

## Fase A — Backbone y backend sintético

Implementar modelos, esquemas, DAG, estados, matrices, gates y pruebas sintéticas.

## Fase B — Backend SIESTA 5.4.x de referencia

Materialización FDF, runtime probe, parser y evidencia. No activar producción hasta cerrar
BARE/SCREENED.

## Fase C — Reproducción histórica

Reprocesar una campaña ya terminada sin cambiar resultados. Comparar observación por observación.

## Fase D — Campaña real mínima

Un sistema pequeño, pocos sitios y una única definición de proyector.

## Fase E — Barrido adaptativo

Alpha pilot, barrido grueso, poda, refinamiento y matriz completa.

## Fase F — Producción

Slurm robusto, reanudación, paquetes autocontenidos y revisión humana.
