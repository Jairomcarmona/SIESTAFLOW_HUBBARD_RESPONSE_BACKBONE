# Mathematical evidence for the finite-difference LR-U campaigns

This document records the mathematical path actually used by the NiO, MnO,
and FeO SC(2x2x2) campaigns. It is a derivation of the production arithmetic,
not an alternate implementation.

## 1. Observables and perturbations

The correlated subspace has 16 Hubbard sites in the 2x2x2 magnetic supercell:
eight translations and two parent sublattices, A and B. For each calculation,
SIESTA prints a semantic Hubbard occupation vector

\[
\mathbf n = (n_0, n_1, \ldots, n_{15})^T,
\qquad n_i \;\text{in electrons}.
\]

A local Hubbard perturbation shifts the on-site projector potential by
`alpha_ev`. The campaigns use symmetric perturbations `+alpha` and `-alpha`
with `alpha = 0.05 eV`, so the central finite difference is

\[
\frac{\partial n_i}{\partial \alpha_j}
\approx
\frac{n_i(+\alpha_j)-n_i(-\alpha_j)}{2\alpha}.
\]

The denominator is therefore `0.10 eV`. The reference occupation is not
subtracted in this derivative: it cancels exactly in the centered difference.
It is used for the reference/state checks and, in the MnO implementation, for
the linearity diagnostic.

## 2. Bare and screened response

For a perturbation on representative site A, define

\[
\mathbf c_A^0
 = \frac{\mathbf n_{A,+}^{\mathrm{BARE}}
              -\mathbf n_{A,-}^{\mathrm{BARE}}}{2\alpha},
\qquad
\mathbf c_A
 = \frac{\mathbf n_{A,+}^{\mathrm{SCREENED}}
              -\mathbf n_{A,-}^{\mathrm{SCREENED}}}{2\alpha}.
\]

The equivalent vectors \(\mathbf c_B^0\) and \(\mathbf c_B\) are formed from
the B perturbations. Each vector has units electrons/eV. These are the two
independent response columns supplied by the explicit SIESTA calculations.

## 3. Translation reconstruction of the 16x16 matrices

The supercell is translationally repeated. Let \(T_t\) be the permutation
that translates a site vector by supercell translation \(t\), where
\(t=0,\ldots,7\). The production reconstruction fills every response column
as

\[
\chi^0_{:,2t} = T_t\mathbf c_A^0,
\qquad
\chi^0_{:,2t+1} = T_t\mathbf c_B^0,
\]

and analogously

\[
\chi_{:,2t} = T_t\mathbf c_A,
\qquad
\chi_{:,,2t+1} = T_t\mathbf c_B.
\]

Thus only four perturbation pairs are executed explicitly (A/B, BARE/SCREENED),
while the 16 columns are generated by the declared supercell translation
symmetry. This is valid only because the campaign geometry, FDFs and site map
declare that symmetry. It is not a generic assumption for an arbitrary
distorted cell.

The raw reconstructed matrices are \(\chi^0_{\rm raw}\) and
\(\chi_{\rm raw}\). The production path removes numerical antisymmetry by
the explicit operation

\[
\chi^0 = \frac{\chi^0_{\rm raw}+(\chi^0_{\rm raw})^T}{2},
\qquad
\chi = \frac{\chi_{\rm raw}+\chi_{\rm raw}^T}{2}.
\]

The unsymmetrized matrices are retained in the evidence directory so the
size of this correction can be reported rather than hidden.

## 4. Hubbard kernel and U

The linear-response kernel is evaluated by direct inversion:

\[
K = (\chi^0)^{-1} - \chi^{-1}.
\]

Since \(\chi\) has units eV\(^{-1}\), both inverse matrices and \(K\) have
units eV. The reported on-site Hubbard parameters are the diagonal entries:

\[
U_i = K_{ii}.
\]

The off-diagonal entries \(K_{ij}\) are retained as intersite response
couplings; they are not used to redefine the reported on-site scalar. A/B
means are summaries over the corresponding eight translated sites.

The implementation uses `numpy.linalg.inv` only after checking full rank. It
does not use a pseudoinverse or silently regularize a singular response.

## 5. Mathematical acceptance tests

For an N=16 campaign, the analysis is accepted only if

\[
\operatorname{rank}(\chi^0)=\operatorname{rank}(\chi)=16,
\]

and the direct-inversion residuals are small:

\[
\| (\chi^0)^{-1}\chi^0-I\|,
\;\|\chi^0(\chi^0)^{-1}-I\|,
\;\|\chi^{-1}\chi-I\|,
\;\|\chi\chi^{-1}-I\|.
\]

The campaigns also preserve the raw-to-symmetric antisymmetry diagnostic

\[
\epsilon_{\rm asym}(A)=
\frac{\|A-A^T\|_F}{\|A\|_F}.
\]

This distinguishes a small numerical asymmetry from a rank or inversion
failure.

The values below are read from the final JSON and matrix artifacts generated
by the completed DAGs.

The site-resolved results are translationally repeated. NiO gives

\[
U_A=7.1597566053\;\mathrm{eV},\qquad
U_B=7.1597612697\;\mathrm{eV},
\]

and MnO gives

\[
U_A=11.5298714570\;\mathrm{eV},\qquad
U_B=11.5337639953\;\mathrm{eV}.
\]

FeO gives

\[
U_A=6.4102398331\;\mathrm{eV},\qquad
U_B=6.4101379259\;\mathrm{eV}.
\]

The scalar reported for each material is the mean over all 16 diagonal
entries. These values are valid for the declared PBE, projector, basis,
supercell, k-grid and perturbation protocol. They are not claims that U is a
universal material constant independent of those choices.

## 7. Evidence needed for an independent audit

The mathematical result can be independently reconstructed from:

1. the nine final `siesta.fdf` files (inputs and perturbation labels);
2. the nine final `siesta.out` files (SCF history and semantic occupations);
3. the nine `0_NORMAL_EXIT` markers and `siesta.err` files;
4. `results/raw_occupations/occupations.json`;
5. `results/matrices/chi0_raw.csv`, `chi0_sym.csv`,
   `chi_screened_raw.csv`, `chi_screened_sym.csv`, inverse matrices and
   `K_hubbard_kernel_ev.csv` (or the corresponding MnO names);
6. the final result JSON and the declared site map/manifest.

The complete tarball remains the immutable raw record. The compact review
bundle contains the files above plus the canonical reference DM needed to
audit parent-to-child handoff, while excluding large generated SIESTA restart
auxiliaries that do not enter the published arithmetic.

## 8. Machine-readable reproduction supplements

The archival evidence is independently re-parsed by
`tools/audit_lr_evidence_tar.py`. It streams one member at a time from the
compressed TAR: it does not import the production SIESTA parser or production
matrix routine, and it does not need to materialize the full archive.

| material | review supplement | raw evidence archive |
|---|---|---|
| NiO | `docs/evidence_audit_nio_20260812.json` | `nio_pbe_lru_sc222_evidence_20260812T073108Z.tar.gz` |
| MnO | `docs/evidence_audit_mno_20260812.json` | `mno_pbe_lru_sc222_evidence_20260812T074252Z.tar.gz` |
| FeO | `docs/evidence_audit_feo_20260812.json` and `docs/evidence/feo_mathematical_20260812/` | `feo_pbe_lru_sc222_mathematical_evidence_20260812T224709Z.tar.gz` |

Each supplement records, for every final run: source member paths, normal
completion status, convergence gate, number of complete Hubbard-occupation
events, selector used, and the selected 16-component occupation vector. It
also records the four explicitly measured response vectors, raw and
symmetrized 16x16 response matrices, both direct inverses, the full Hubbard
kernel, all sixteen on-site diagonal values, rank, condition number, and
inversion residuals. Thus every published scalar can be recalculated from
the native OUT evidence without trusting a manually transcribed number.

## 9. Scope of the mathematical claim

This evidence establishes numerical and workflow correctness for the declared
finite-difference calculation: the accepted SIESTA outputs yield a complete,
well-conditioned response matrix and a directly invertible Hubbard kernel.
It does **not** alone establish that the resulting scalar is a universal or
fully converged physical material constant. That latter claim additionally
requires a predeclared convergence study over the physically relevant
approximations (for example supercell extent, k-point sampling, localized
subspace/projector definition, basis and grid), and comparison to an
independent reference where appropriate. Those studies must report their
criteria and results rather than merely replacing this baseline value.
