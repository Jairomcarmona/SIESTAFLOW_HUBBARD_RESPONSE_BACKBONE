# Cu3N: symmetry-reduction audit

## Scope and provenance

This record analyzes the campaign *offline*:
`CU3N_PBE_LRU_SC222_RC3p0_V1` contained in the original evidence archive
`cu3n_mathematical_evidence_20260812T210120Z.tar.gz`.

- Archive SHA-256: `76f5effd3d124d1723725a9f30d4ac17056b4d892f73b4c14c6028f96a87f11f`.
- The analysis used `runs/00_REFERENCE/siesta.fdf`,
  `runs/00_REFERENCE/siesta.out`, `occupations.json`, `chi0.csv`, `chi.csv` y
  `U_by_site.csv` from the same file.
- SIESTA was not run and the original campaign was not modified.

## Magnetic-state gate

The FDF declares `Spin non-polarized`. The SIESTA 5.4.2 output confirms
`Spin configuration = none`, a single spin component, and
active time-reversal symmetry, as well as normal termination. Therefore, the
zero-moment field was certified for all 32 atoms; `DM.InitSpin` was not used
as evidence.

## Geometric and subspace result

The conservative auditor found 384 candidate geometric operations and eight
operations that preserve geometry, the non-magnetic state, and the
local subspace definition simultaneously. Orbital rotations are not
certified: the result permits only translations that preserve the explicit
projector definitions.

The 24 correlated Cu sites form three orbits of eight sites:

| orbit | correlated Cu indices |
| --- | --- |
| X | 0, 3, 6, 9, 12, 15, 18, 21 |
| Y | 1, 4, 7, 10, 13, 16, 19, 22 |
| Z | 2, 5, 8, 11, 14, 17, 20, 23 |

## Consistency of the archived reconstruction

For each of the eight certified operations, the following was evaluated:

\[
\max_{I,J}\left|\chi^{(0)}_{IJ}-\chi^{(0)}_{p(I)p(J)}\right|,
\qquad
\max_{I,J}\left|\chi_{IJ}-\chi_{p(I)p(J)}\right|.
\]

Both maximum residuals were exactly `0.0` in the archived CSV files. The
maximum-to-minimum ranges of \(U_I\) within orbits X, Y, and Z were,
respectively, \(8.88\times10^{-15}\), \(0.0\), and
\(1.95\times10^{-14}\) eV. This confirms that the indices, permutations,
and stored reconstruction are internally consistent.

## Scientific limitation: this is not yet an independent validation

The archive contains twelve explicit perturbations: \(\pm\alpha\), BARE, and
SCREENED for representatives X, Y, and Z. The columns for the other 21 Cu
sites were generated by symmetry reconstruction. Therefore, exact equality of
the matrices above is expected and **does not** by itself prove that a second
SIESTA perturbation of a translated site reproduces its representative.

Before enabling automatic reduction in production campaigns, a shadow test
must be run for each orbit: select a translated Cu site that has not been
perturbed, run BARE \(\pm\alpha\) and SCREENED \(\pm\alpha\), and compare its
directly calculated column with the representative's translated column. The
campaign may authorize reduction only if all four responses satisfy
predefined physical and numerical tolerances.
