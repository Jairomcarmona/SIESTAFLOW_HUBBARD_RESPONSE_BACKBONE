# Roadmap to a Valid U

This document tracks the strategic milestones required to transform the SIESTAFLOW Hubbard Response Backbone from its initial prototype state into a scientifically auditable framework.

## Phases
1. **AUTHORITATIVE SIESTA 5.4.2 CONTRACT**: Verify exact physics of SIESTA 5.4.2.
2. **SAFE FDF MATERIALIZATION**: Robust serialization and domain objects.
3. **EVENT-ORIENTED SIESTA OUTPUT PARSER**: Precise tracking of SCF and Hubbard population events.
4. **BARE/SCREENED PROTOCOL**: Validated mapping of $n_0(\alpha)$ and $n(\alpha)$.
5. **REAL REGRESSION AND LINEARITY GATES**: Strict statistical analysis of linear response.
6. **MULTISITE RESPONSE MATRIX**: Explicit subspace tracking and gauge policies.
7. **U CONSTRUCTION AND UNCERTAINTY**: Validated matrix inversion.
8. **WORKFLOW, CLI, RESUME, EVIDENCE**: State models and command-line interfaces.
9. **REMOVE CORE HARDCODING**: Generalization of the core framework.
10. **ADVERSARIAL RELEASE AUDIT**: Final security and physics checks.
