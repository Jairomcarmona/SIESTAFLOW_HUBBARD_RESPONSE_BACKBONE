# β-MnO₂ native-output evidence supplement

This directory records an independent mathematical audit of the PBE
finite-difference LR-U campaign for pyrolusite β-MnO₂.  The complete numeric
supplement is [`../../evidence_audit_beta_mno2_20260812.json`](../../evidence_audit_beta_mno2_20260812.json), reconstructed from native SIESTA output, rather than read from the packaged campaign result.

The formal derivation is in `BETA_MNO2_LR_U_MATHEMATICAL_EVIDENCE.md`; the
complete human-readable matrices are in `BETA_MNO2_COMPLETE_NUMERICAL_APPENDIX.md`;
and adversarial checks are recorded in `ADVERSARIAL_AUDIT.md`.
