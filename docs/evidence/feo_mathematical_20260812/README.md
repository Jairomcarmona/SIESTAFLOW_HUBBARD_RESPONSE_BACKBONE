# FeO native-output evidence supplement

This directory records the independent mathematical audit of the FeO
finite-difference linear-response Hubbard campaign.  The machine-readable
result is [`../../evidence_audit_feo_20260812.json`](../../evidence_audit_feo_20260812.json).
It was reconstructed from the native SIESTA `siesta.out`, `siesta.err`, and
`0_NORMAL_EXIT` members of the archived calculation; it does not use the
campaign result JSON as an input.

The source archive is retained outside Git because it contains native output
and is substantially larger than source documentation.  Its SHA-256 is given
in the accompanying mathematical evidence report.
